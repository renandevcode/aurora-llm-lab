# Pacote do projeto Aurora

A pasta [Aurora](Aurora/README.md) contém o laboratório completo. Ela é a unidade de cópia para o repositório Projetos: o destino proposto é `projects/Individual/Aurora/`.

Copie o conteúdo da pasta, incluindo `.gitignore`, documentação e dados fictícios. Prepare o ambiente virtual e execute os comandos a partir de `Aurora/`, conforme seu README. A aplicação não depende dos diretórios `aula/` ou `cli/` deste repositório para funcionar.

A documentação inclui links complementares para a aula no GitHub. O estudo técnico, os exercícios de programação e os testes ficam dentro do pacote.

A integração futura também pode incluir uma entrada no catálogo geral de Projetos, conforme a decisão dos mantenedores. O README do Aurora descreve somente este laboratório e não substitui o catálogo da Liga.
