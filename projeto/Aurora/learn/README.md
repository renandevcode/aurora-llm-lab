# Trilha de aprendizagem do Aurora Prompt Lab

Esta trilha explica o laboratório desde os fundamentos até uma extensão de programação. Você vai entender o contexto de um modelo de linguagem, acompanhar uma requisição no código, observar os exercícios e implementar uma defesa com critérios de conclusão.

O projeto desta pasta é uma aplicação web com FastAPI e Ollama. Os comandos e arquivos descritos nos módulos correspondem a essa versão.

## Ordem de leitura

| Módulo | Pergunta principal | Resultado da etapa |
| --- | --- | --- |
| [00 — Introdução](00-introducao.md) | O que vou estudar e por que isso importa? | Objetivos, pré-requisitos e plano de estudo |
| [01 — Conceitos](01-conceitos.md) | Qual é a diferença entre contexto, instrução e permissão? | Vocabulário para interpretar os experimentos |

| [04 — Desafios](04-desafios.md) | Como transformar compreensão em investigação e código? | Atividades graduais e MVP defensivo |

Os tempos indicados nos módulos são estimativas de leitura, sem contar instalação, download, geração do modelo ou implementação dos desafios.

## Escolha seu percurso

**Primeiro contato:** leia introdução e conceitos, prepare o ambiente no módulo 03 e explore a interface. A [aula curta](https://github.com/renandevcode/aurora-llm-lab/blob/main/aula/inspersec/docs/aulas/redTeam/aulasextras/aurora.md) organiza duas sessões de 90 minutos.

**Estudo do projeto:** percorra todos os módulos e faça o MVP de programação do módulo 04. Os exercícios do chat permitem observar o sistema; a extensão defensiva exige alterar código e verificar o resultado.

**Docência:** use a aula curta, o [guia docente](../GUIA_DOCENTE.md) e os critérios de entrega. Combine previamente se a turma fará apenas a investigação ou também a extensão de programação.

## Como usar o material sem antecipar respostas

Para investigar os desafios pela conversa, faça primeiro as tentativas pela interface e registre o que observou. A leitura posterior da arquitetura e do código explica os mecanismos, mas não comprova que uma descoberta veio do chat. Não inclua valores obtidos dos arquivos internos como resultado de uma tentativa pela interface.

A instalação completa está no [README do projeto](../README.md). As evidências de verificação da versão entregue estão no [relatório local](../docs/VALIDACAO.md); seus próprios experimentos devem ser registrados separadamente.
